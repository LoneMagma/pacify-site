# Pacify

A static project workshop for LoneMagma, with live previews for healthy deployed work.

## Run locally

From this directory:

```bash
python3 -m http.server 8080
```

Then open `http://127.0.0.1:8080`.

## Deploy

The folder is a dependency-free static site. Upload it directly to Vercel or any static host.

Project content is present in `index.html`, so the page remains complete for search engines, assistive technology and visitors without JavaScript. JavaScript only controls weather persistence and the subtle background movement.
